# 5.3 เครื่องมือที่ใช้ในการพัฒนาระบบ (Development Tools)

เครื่องมือและเทคโนโลยีที่คาดว่าจะเลือกใช้ในการพัฒนาระบบแอปพลิเคชันจัดการการตรวจนิเทศงานสหกิจศึกษามีดังต่อไปนี้:

### 5.3.1 JavaScript
JavaScript คือภาษาโปรแกรมสำหรับพัฒนาเว็บเพจให้มีการทำงานแบบโต้ตอบ (Interactive) สามารถตอบสนองการกระทำของผู้ใช้งานได้ทันทีโดยไม่ต้องโหลดหน้าเว็บใหม่ ในโครงงานนี้ JavaScript ถูกนำมาใช้ในการพัฒนาระบบรับส่งข้อมูลและสร้างกลไกการโต้ตอบบนหน้าจอแอปพลิเคชัน เช่น การสลับหน้าจอการใช้งานของอาจารย์นิเทศและนิสิต รวมถึงการประมวลผลคำขอเช็กอินแบบเรียลไทม์

### 5.3.2 React.js
React.js คือไลบรารี JavaScript ที่พัฒนาโดย Meta สำหรับสร้างส่วนติดต่อผู้ใช้ (User Interface) ในรูปแบบ Single Page Application (SPA) โดยถูกนำมาใช้ในการพัฒนาหน้าจอแอปพลิเคชันระบบนิเทศสหกิจศึกษาให้มีโครงสร้างที่ลื่นไหล ตอบสนองอย่างรวดเร็ว และมีการออกแบบในรูปแบบ Responsive Design เพื่อให้ผู้ใช้สามารถเปิดใช้งานผ่านสมาร์ตโฟนได้อย่างสะดวกและมีประสิทธิภาพ

### 5.3.3 Supabase
Supabase คือแพลตฟอร์ม Backend-as-a-Service (BaaS) แบบ Open-source ที่พัฒนาขึ้นบนฐานข้อมูล PostgreSQL ประสิทธิภาพสูง โดยในโครงงานนี้จะนำมาใช้งานใน 3 ส่วนหลัก ได้แก่:
1. **Supabase Database (PostgreSQL):** สำหรับจัดเก็บข้อมูลรายชื่ออาจารย์และนิสิต แยกตามกลุ่มหมู่เรียน ข้อมูลการจัดนัดหมายปฏิทิน และประวัติพิกัด GPS
2. **Supabase Auth:** สำหรับจัดการระบบลงทะเบียนสมาชิก ยืนยันตัวตน และควบคุมสิทธิ์การเข้าใช้งานของแต่ละสถานะ (นิสิต / อาจารย์ / ผู้ดูแลระบบ)
3. **Supabase Storage:** สำหรับจัดเก็บไฟล์เอกสารแนบประกอบหลักฐานต่าง ๆ เช่น รูปภาพหลักฐานการออกตรวจนิเทศงานจริงของอาจารย์

### 5.3.4 HTML5 และ CSS3 (รวมถึง Tailwind CSS)
HTML5 คือภาษาโครงสร้างหลักที่ใช้กำหนดเนื้อหาและจัดองค์ประกอบต่าง ๆ บนหน้าเว็บเพจ ขณะที่ CSS3 เป็นภาษาที่ใช้ในการจัดแต่งสไตล์การแสดงผลเพื่อความสวยงาม และมี Tailwind CSS ซึ่งเป็น Utility-first CSS Framework ที่ช่วยให้การเขียนโค้ดเพื่อออกแบบส่วนติดต่อผู้ใช้ (UI) เป็นไปอย่างรวดเร็ว โดยในโครงงานนี้จะใช้ HTML5 ในการวางโครงสร้างอินพุต ฟอร์ม และปุ่มต่าง ๆ ส่วน Tailwind CSS จะเข้ามาช่วยจัดการจัดวางเลย์เอาต์ ปรับแต่งปุ่มกด สีสัน และการทำ Responsive Design เพื่อให้แอปพลิเคชันสลับหน้าจอการแสดงผลให้เหมาะสมและสวยงามได้ทั้งบนสมาร์ตโฟนและหน้า Web Dashboard ของผู้ดูแลระบบโดยไม่ต้องเขียนไฟล์ CSS แยกต่างหาก

### 5.3.5 Geolocation API และ Leaflet.js
Geolocation API คืออินเทอร์เฟซมาตรฐานในระบบเว็บบราวเซอร์ที่ใช้ในการเข้าถึงข้อมูลพิกัดตำแหน่งทางภูมิศาสตร์จากฮาร์ดแวร์ GPS ของอุปกรณ์ผู้ใช้งาน ส่วน Leaflet.js คือโอเพนซอร์สไลบรารีประเภท JavaScript ที่ออกแบบมาสำหรับการสร้างแผนที่แบบโต้ตอบ (Interactive Maps) ที่มีขนาดเล็กและประมวลผลได้รวดเร็ว โดยในโครงงานนี้เทคโนโลยีทั้งสองถูกนำมาใช้ร่วมกันในการดึงพิกัดละติจูดและลองจิจูดของอาจารย์ขณะทำการสแกนเช็กอินผ่าน QR Code เพื่อส่งข้อมูลไปตรวจสอบตำแหน่ง และใช้แสดงพิกัดแผนที่แบบจุดปักในฝั่งของผู้ดูแลระบบ

### 5.3.6 SheetJS (xlsx) และ jsPDF
SheetJS (หรือ xlsx) คือไลบรารีภาษา JavaScript ที่มีความสามารถในการประมวลผลและสร้างไฟล์สเปรดชีต Excel ส่วน jsPDF คือไลบรารีภาษา JavaScript ที่ช่วยในการสร้างและจัดรูปแบบหน้าเอกสาร PDF จากทางฝั่งของไคลเอนต์โดยตรง โดยในโครงงานนี้จะนำมาใช้ในส่วนของผู้ดูแลระบบ (Admin) สำหรับแปลงประวัติข้อมูลการออกตรวจและประเมินนิสิตให้ออกมาเป็นตารางสรุปรายงานในรูปแบบไฟล์ Excel (.xlsx) และจัดรูปแบบสำหรับดาวน์โหลดเป็นไฟล์ PDF (.pdf) ได้ทันทีผ่านหน้า Dashboard

### 5.3.7 Vite
Vite คือเครื่องมือสร้างและจัดการโปรเจกต์ต้นแบบ (Frontend Build Tool) ยุคใหม่สำหรับเว็บแอปพลิเคชันที่ทำงานโดยอิงตามระบบ ECMAScript Modules (ESM) เพื่อความเร็วสูงสุดในการพัฒนาและคอมไพล์ระบบ โดยในโครงงานนี้ Vite ถูกนำมาใช้ในการรันสภาพแวดล้อมเพื่อพัฒนา (Development Environment) โดยมีระบบ Hot Module Replacement (HMR) ที่ช่วยอัปเดตการแสดงผลทันทีที่มีการแก้ไขโค้ด และใช้ในการรวมไฟล์บีบอัดโค้ด (Bundling) ทั้งหมดของ React.js, Tailwind CSS และ JavaScript ให้มีขนาดเล็กและมีประสิทธิภาพสูงสุดในการดาวน์โหลดหน้าเว็บเมื่อนำระบบขึ้นติดตั้งใช้งานจริง
