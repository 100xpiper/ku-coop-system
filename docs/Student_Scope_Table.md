# 3. ขอบเขตของโครงงาน (Scope of Project)

## ขอบเขตการใช้งาน (User Scope) - ฝ่ายนิสิตสหกิจศึกษา (Student)

ตารางขอบเขตการทำงานของนิสิตสหกิจศึกษาแสดงรายละเอียดฟังก์ชันการทำงาน หมายเหตุ และเปอร์เซ็นต์ความสำเร็จของระบบดังนี้:

| ฟังก์ชันการทำงาน | รายละเอียด | หมายเหตุ | ความสำเร็จ |
| :--- | :--- | :---: | :---: |
| **1. ลงทะเบียนและเข้าสู่ระบบ** | ⬜ 1.1 นิสิตลงทะเบียนเข้าใช้งานแอปพลิเคชันด้วยอีเมลมหาวิทยาลัย (@ku.th) และตั้งรหัสผ่าน โดยระบบจะตรวจสอบสิทธิ์ Pre-registered หากผ่านเกณฑ์จะคัดกรองบทบาทเป็น "นิสิตสหกิจศึกษา" โดยอัตโนมัติ | | 100% |
| | ⬜ 1.2 นิสิตเข้าสู่ระบบผ่านแอปพลิเคชันเพื่อเริ่มต้นใช้งานด้วยบัญชีที่ลงทะเบียนไว้ | | 100% |
| | ⬜ 1.3 นิสิตสามารถออกจากระบบ (Logout) เพื่อความปลอดภัยของข้อมูลบัญชีผู้ใช้ได้ | | 100% |
| **2. ตรวจสอบข้อมูลความก้าวหน้า**| ⬜ 2.1 นิสิตสามารถอัปโหลดความคืบหน้าของตนเอง ตรวจประวัติสถานะความถูกต้อง และตรวจสอบผลการอนุมัติการส่งเอกสารแบบฟอร์ม 0-11 ได้ | | 100% |
| | ⬜ 2.2 นิสิตสามารถเรียกดูรายงานผลประเมินคะแนนนิเทศสหกิจศึกษาและข้อคิดเห็นสะท้อนกลับจากอาจารย์ได้ทันทีเมื่ออาจารย์บันทึกผลเข้าระบบสำเร็จ | | 100% |
| **3. ตรวจสอบปฏิทินนัดหมาย** | ⬜ 3.1 นิสิตสามารถเข้าตรวจสอบวันและเวลา รวมถึงสถานที่ลงพื้นที่ของอาจารย์ที่จะออกนิเทศงานล่วงหน้าผ่านทางหน้าจอปฏิทินของแอปพลิเคชันได้เพื่อวางแผนประสานงานพี่เลี้ยง | | 100% |
| **4. ยืนยันตัวตนด้วย QR Code** | ⬜ 4.1 นิสิตสามารถเปิดแสดงคิวอาร์โค้ดประจำตัวของตนเอง (Static QR Code) ผ่านโทรศัพท์มือถือเพื่อให้อาจารย์สแกนเช็คอินลงนิเทศงานจริงได้ | | 100% |
