# 3. ขอบเขตของโครงงาน (Scope of Project)

## ขอบเขตของใช้งาน (User Scope) - ฝ่ายผู้ดูแลระบบ (Admin)

ตารางขอบเขตการทำงานของผู้ดูแลระบบแสดงรายละเอียดฟังก์ชันการทำงาน หมายเหตุ และเปอร์เซ็นต์ความสำเร็จของระบบดังนี้:

| ฟังก์ชันการทำงาน | รายละเอียด | หมายเหตุ | ความสำเร็จ |
| :--- | :--- | :---: | :---: |
| **1. นำเข้าข้อมูลรายชื่อผู้ใช้** | ⬜ 1.1 ผู้ดูแลระบบสามารถอัปโหลดไฟล์ตารางข้อมูลดิบ (Excel/CSV) รายชื่อนิสิตและอาจารย์ที่ปรึกษาที่ได้รับอนุมัติสิทธิ์เข้าสู่ระบบฐานข้อมูล Supabase เพื่อลงทะเบียนล่วงหน้าได้ | | 100% |
| | ⬜ 1.2 ผู้ดูแลระบบสามารถเข้าสู่ระบบผ่านหน้า Web Dashboard เพื่อการจัดการภาพรวมระบบหลังบ้านได้ | | 100% |
| | ⬜ 1.3 ผู้ดูแลระบบสามารถออกจากระบบเพื่อความปลอดภัยในการเข้าถึงฐานข้อมูลกลางได้ | | 100% |
| **2. ตรวจสอบข้อมูลความคืบหน้า** | ⬜ 2.1 ผู้ดูแลระบบสามารถติดตามตรวจสอบสถิติการตรวจนิเทศงานแยกตามหมู่เรียน (หมู่ 700 และ 800) ของอาจารย์ทุกท่านแบบ Real-time | | 100% |
| | ⬜ 2.2 ผู้ดูแลระบบสามารถค้นหาและกรองตรวจสอบการส่งเอกสาร Form 0-11 ของนิสิตเป็นรายบุคคลได้ | | 100% |
| **3. ตั้งค่าพิกัดสถานประกอบการ** | ⬜ 3.1 ผู้ดูแลระบบสามารถระบุพิกัดจีพีเอส (ละติจูด/ลองจิจูด) ของสถานที่ตั้งสถานประกอบการของนิสิตแต่ละคนเข้าสู่ฐานข้อมูลได้ เพื่อเป็นฐานข้อมูลตรวจสอบพิกัดตอนเช็คอิน | | 100% |
| **4. สรุปรายงานและส่งออกไฟล์** | ⬜ 4.1 ผู้ดูแลระบบสามารถประมวลผลข้อมูลการลงพื้นที่และดาวน์โหลดไฟล์รายงาน Excel (.xlsx) สรุปประวัติการตรวจนิเทศงานแยกตามกลุ่มได้ | | 100% |
| | ⬜ 4.2 ผู้ดูแลระบบสามารถดาวน์โหลดใบสรุปผลประเมินคะแนนนิเทศของนิสิตทั้งหมดเป็นรูปแบบไฟล์ PDF (.pdf) ได้ | | 100% |
