# 3. ขอบเขตของโครงงาน (Scope of Project)

## ขอบเขตการใช้งาน (User Scope) - ฝ่ายอาจารย์นิเทศ (Advisor)

ตารางขอบเขตการทำงานของอาจารย์นิเทศแสดงรายละเอียดฟังก์ชันการทำงาน หมายเหตุ และเปอร์เซ็นต์ความสำเร็จของระบบดังนี้:

| ฟังก์ชันการทำงาน | รายละเอียด | หมายเหตุ | ความสำเร็จ |
| :--- | :--- | :---: | :---: |
| **1. ลงทะเบียนและเข้าสู่ระบบ** | ⬜ 1.1 อาจารย์ลงทะเบียนเข้าใช้งานแอปพลิเคชันด้วยอีเมลมหาวิทยาลัย (@ku.th) และตั้งรหัสผ่าน โดยระบบจะตรวจสอบสิทธิ์ Pre-registered หากผ่านเกณฑ์จะคัดกรองบทบาทเป็น "อาจารย์นิเทศ" โดยอัตโนมัติ | | 100% |
| | ⬜ 1.2 อาจารย์เข้าสู่ระบบผ่านแอปพลิเคชันเพื่อเริ่มต้นใช้งานด้วยบัญชีที่ลงทะเบียนไว้ | | 100% |
| | ⬜ 1.3 อาจารย์สามารถออกจากระบบ (Logout) เพื่อความปลอดภัยของข้อมูลบัญชีผู้ใช้ได้ | | 100% |
| **2. จัดการห้องเรียนจำลอง** | ⬜ 2.1 อาจารย์สามารถเข้าตรวจสอบรายชื่อ ข้อมูลเบื้องต้น และสถานที่ฝึกงานของนิสิตทุกคนในหมู่เรียนความดูแล (หมู่ 700 และ 800) ได้ในหน้าเดียว | | 100% |
| | ⬜ 2.2 อาจารย์สามารถตรวจเช็คประวัติการส่งแบบฟอร์มเอกสาร 0-11 ของนิสิตรายคน รวมถึงกดยกเลิกการตรวจเพื่อส่งตีกลับแก้ไขได้ | | 100% |
| **3. จัดการนัดหมายปฏิทิน** | ⬜ 3.1 อาจารย์สามารถวางแผนและกำหนดการนัดหมายลงตรวจนิเทศงานล่วงหน้า โดยระบุรายชื่อนิสิต วันที่ และเลือกเวลาผ่านเมนู Dropdown ลงบนปฏิทินได้ | | 100% |
| | ⬜ 3.2 อาจารย์สามารถกดล้างฟอร์มยกเลิกข้อมูลนัดหมายก่อนกดยืนยันบันทึกได้ | | 100% |
| **4. จัดการรูปภาพหลักฐาน** | ⬜ 4.1 อาจารย์สามารถเข้าสู่หน้ารายการรายชื่อนิสิตเพื่อจัดการอัปโหลด ถ่ายรูปภาพ หรือเปลี่ยนไฟล์ภาพหลักฐานการออกตรวจนิเทศจริงของนิสิตรายบุคคลได้ | | 100% |
| | ⬜ 4.2 อาจารย์สามารถกดปุ่ม "ลบรูปภาพหลักฐาน" เพื่อลบรูปถ่ายหลักฐานตรวจนิเทศของนิสิตรายคนออกจากฐานข้อมูลระบบคลาวด์ได้ | | 100% |
| **5. สแกนคิวอาร์เช็คอิน** | ⬜ 5.1 อาจารย์สามารถเปิดกล้องในแอปพลิเคชันสแกน QR Code ประจำตัวนิสิตเพื่อทำการยืนยันพิกัด ณ สถานประกอบการจริง | | 100% |
| | ⬜ 5.2 ระบบทำการดึงค่าพิกัดจีพีเอส (GPS Geolocation) บันทึกและเปลี่ยนสถานะของนิสิตเป็น "นิเทศแล้ว" ทันทีหลังเช็คอินสำเร็จ | | 100% |
