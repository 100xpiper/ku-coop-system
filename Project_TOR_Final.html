1. ที่มาและความสำคัญ

กระบวนการจัดการการตรวจนิเทศงานสหกิจศึกษาของภาควิชาวิทยาการคอมพิวเตอร์ คณะวิทยาศาสตร์ มหาวิทยาลัยเกษตรศาสตร์ ถือเป็นกลไกสำคัญในการประกันคุณภาพการเรียนรู้และการฝึกประสบการณ์วิชาชีพของนิสิตในสถานประกอบการจริง อย่างไรก็ดี จากการศึกษาสภาพการดำเนินงานในปัจจุบัน พบว่ายังมีข้อจำกัดและปัญหาสำคัญ 4 ประการ ดังนี้:

  • ปัญหาการจัดการเอกสารกระดาษและความล่าช้า: การประเมินผลและการส่งแบบฟอร์มทางการ Form 01 ถึง Form 11 ยังใช้รูปแบบเอกสารกระดาษหรือการส่งไฟล์กระจัดกระจาย ทำให้เกิดปัญหาเอกสารสูญหาย ไม่สามารถตรวจสอบย้อนหลังได้ทันท่วงที และภาระงานตรวจรับเอกสารของอาจารย์นิเทศมีความซ้ำซ้อน
  • ความยากลำบากในการติดตามความคืบหน้ารายบุคคลและการแยกหมู่เรียน: ในแต่ละภาคการศึกษา มีนิสิตออกฝึกสหกิจศึกษาจำนวนมากแบ่งออกเป็นหมู่ 700 (ภาคปกติ) และหมู่ 800 (ภาคพิเศษ) การติดตามสถานะการส่งงานและการออกนิเทศของอาจารย์แต่ละท่านแบบเรียลไทม์ไม่สามารถทำได้อย่างมีเอกภาพ
  • ปัญหาการนัดหมายลงพื้นที่ตรวจนิเทศคลาดเคลื่อน: ตารางเวลาของอาจารย์นิเทศ นิสิต และพนักงานพี่เลี้ยงในสถานประกอบการมักเกิดความซ้ำซ้อนหรือคลาดเคลื่อน เนื่องจากไม่มีระบบปฏิทินกลางที่แสดงผลนัดหมายระบุวันตรงกัน
  • การขาดพยานหลักฐานเชิงประจักษ์ยืนยันการลงพื้นที่จริง: ในการตรวจนิเทศงานยังขาดกลไกที่เชื่อถือได้และโปร่งใสในการยืนยันว่าอาจารย์ได้เดินทางไปตรวจนิเทศ ณ สถานประกอบการจริงตามเกณฑ์มาตรฐาน

เพื่อแก้ไขปัญหาดังกล่าว ผู้จัดทำจึงได้พัฒนา "ระบบจัดการการตรวจนิเทศงานสหกิจศึกษา คณะวิทยาศาสตร์ มหาวิทยาลัยเกษตรศาสตร์ (KU Science Smart Internship Supervision Platform)" ขึ้นในรูปแบบเว็บแอปพลิเคชันแบบตอบสนอง (Responsive Single Page Application) รองรับการใช้งานทั้งคอมพิวเตอร์ แท็บเล็ต และสมาร์ทโฟน โดยบูรณาการเทคโนโลยีกล้องสดสแกน QR Code แบบเรียลไทม์ ระบบตรวจสอบพิกัดภูมิศาสตร์ (Geolocation API) จำกัดรัศมีการเช็คอินไม่เกิน 500 เมตร (500m Geo-Fencing) คลังภาพถ่ายหลักฐานการนิเทศงาน (Supervision Evidence Gallery) และระบบความปลอดภัยยืนยันตัวตนด้วยรหัส OTP 8 หลัก ผ่านอีเมลมหาวิทยาลัย (@ku.th)

คำสำคัญ : ระบบจัดการนิเทศงานสหกิจศึกษา, การตรวจนิเทศงาน, สแกน QR Code เช็คอิน, Geolocation API พิกัด GPS, ยืนยันตัวตน OTP, Supabase Cloud Database

2. วัตถุประสงค์

  1. เพื่อพัฒนาระบบเว็บแอปพลิเคชันสำหรับบริหารจัดการการตรวจนิเทศงานสหกิจศึกษา คณะวิทยาศาสตร์ มหาวิทยาลัยเกษตรศาสตร์ ที่รองรับการทำงาน 3 บทบาท (ผู้ดูแลระบบ, อาจารย์นิเทศ, นิสิตสหกิจศึกษา)
  2. เพื่อพัฒนาระบบตรวจสอบและยืนยันการลงพื้นที่นิเทศงานจริง ณ สถานประกอบการ ด้วยการผสานเทคโนโลยี Dynamic QR Code สแกนเนอร์ และระบบตรวจสอบพิกัด Geolocation API แบบจำกัดรัศมีปลอดภัยไม่เกิน 500 เมตร (500m Geo-Fencing)
  3. เพื่อพัฒนาระบบบันทึกและจัดเก็บภาพถ่ายหลักฐานการลงพื้นที่นิเทศงานจริง (Supervision Evidence Gallery) พร้อมกลไกการยืนยันการอัปโหลดสองชั้น
  4. เพื่อพัฒนาระบบบริหารจัดการข้อมูลนิสิตผ่านการนำเข้าไฟล์ Excel ขนาดใหญ่แบบพรีวิวเต็มความกว้าง 100% และระบบส่งออกรายงานสรุปผลการนิเทศงานในรูปแบบ Excel และ PDF
  5. เพื่อพัฒนาระบบปฏิทินนัดหมายแบบระบุวันตรงกัน และระบบติดตามตรวจสอบสถานะการส่งเอกสารแบบฟอร์ม Form 01 - 11 แบบเรียลไทม์

3. ขอบเขตของโครงงาน (Scope of Project)

ขอบเขตการทำงานของระบบถูกออกแบบตามสิทธิ์และหน้าที่ของผู้ใช้งาน 3 ฝ่าย (User Scope) โดยในแต่ละฟังก์ชันได้ระบุรายละเอียด หมายเหตุการพัฒนาฟังก์ชันใหม่ และระดับความสำเร็จ ดังตารางต่อไปนี้:

3.1 ขอบเขตของผู้ดูแลระบบ (System Administrator)

\n\n\n\n\n\n\n\n\n\n\n\n
ฟังก์ชันการทำงาน รายละเอียด หมายเหตุ ความสำเร็จ
1. นำเข้าข้อมูลรายชื่อผู้ใช้ ☑ 1.1 ผู้ดูแลระบบสามารถอัปโหลดไฟล์ตารางข้อมูลดิบ (Excel/CSV) รายชื่อนิสิตและอาจารย์ที่ปรึกษาที่ได้รับอนุมัติสิทธิ์เข้าสู่ระบบฐานข้อมูล Supabase เพื่อลงทะเบียนล่วงหน้าได้ จากเดิมที่อัปโหลดไฟล์ข้อมูลดิบเข้าสู่ฐานข้อมูลทันทีโดยไม่มีการตรวจสอบข้อมูล จึงได้มีการเพิ่มฟังก์ชันการทำงานตามข้อที่ 1.4 และ 1.5 100%
☑ 1.2 ผู้ดูแลระบบสามารถเข้าสู่ระบบผ่านหน้า Web Dashboard เพื่อการจัดการภาพรวมระบบหลังบ้านได้ มีการเพิ่มระบบตรวจสอบสิทธิ์และยืนยันตัวตนความปลอดภัย 2 ชั้นด้วยรหัส OTP เพิ่มเติมตามข้อ 1.6 100%
☑ 1.3 ผู้ดูแลระบบสามารถออกจากระบบ (Logout) เพื่อความปลอดภัยในการเข้าถึงฐานข้อมูลกลางได้ - 100%
☑ 1.4 ระบบพรีวิวข้อมูลไฟล์ Excel ขนาดใหญ่แบบเต็มความกว้าง (100% Full Width Preview) ความสูง 420px แสดงรายละเอียดครบ 7 คอลัมน์ พร้อมแท็กสรุปยอดจำนวนนิสิตแยกตามหมู่เรียน (หมู่ 700 / 800) ก่อนกดยืนยันนำเข้าข้อมูล (Pre-Import Preview) ฟังก์ชันพัฒนาใหม่/ปรับปรุง
เป็นการปรับปรุงและเพิ่มฟังก์ชันการทำงานต่อจากข้อ 1.1 เพื่อให้ผู้ดูแลระบบสามารถตรวจสอบความถูกต้องของข้อมูลรายชื่อ รหัสนิสิต และหมู่เรียน ก่อนบันทึกลงฐานข้อมูลจริง ป้องกันปัญหาการนำเข้าข้อมูลซ้ำซ้อนหรือตกหล่น		 100%
☑ 1.5 ระบบพรีวิวและตรวจสอบผลลัพธ์หลังการนำเข้าข้อมูล (Post-Import Preview) พร้อมตัดคอลัมน์สถานะการยืนยันออก ฟังก์ชันพัฒนาใหม่/ปรับปรุง
เป็นการปรับปรุงส่วนติดต่อผู้ใช้ต่อจากข้อ 1.4 โดยปรับโครงสร้างตารางแสดงผลหลังการนำเข้าให้สอดคล้องกับระเบียบงานทะเบียนคณะฯ และตัดคอลัมน์สถานะที่ไม่จำเป็นออกเพื่อความกระชับชัดเจน		 100%
☑ 1.6 ระบบยืนยันตัวตนและรักษาความปลอดภัยด้วยรหัสผ่านใช้ครั้งเดียว (OTP 8 หลัก) ผ่านอีเมลมหาวิทยาลัย (@ku.th) เป็นการยกระดับความปลอดภัยต่อจากข้อ 1.2 เพื่อป้องกันการเข้าถึงแดชบอร์ดของผู้ดูแลระบบโดยไม่ได้รับอนุญาต 100%
2. ตรวจสอบข้อมูลความคืบหน้า ☑ 2.1 ผู้ดูแลระบบสามารถติดตามตรวจสอบสถิติการตรวจนิเทศงานแยกตามหมู่เรียน (หมู่ 700 ภาคปกติ และหมู่ 800 ภาคพิเศษ) ของอาจารย์ทุกท่านแบบ Real-time - 100%
☑ 2.2 ผู้ดูแลระบบสามารถค้นหาและกรองตรวจสอบการส่งเอกสาร Form 01 - 11 ของนิสิตเป็นรายบุคคลได้ จากเดิมที่แถบค้นหาจะเลื่อนหายไปตามการเลื่อนหน้าจอ จึงได้มีการเพิ่มฟังก์ชันการทำงานตามข้อ 2.3 100%
☑ 2.3 ระบบแถบค้นหาและตัวกรองข้อมูลแบบคงที่ (Static Sticky Search Bar) สำหรับค้นหารายชื่อนิสิตและอาจารย์ ฟังก์ชันพัฒนาใหม่/ปรับปรุง
เป็นการปรับปรุงส่วนติดต่อผู้ใช้ต่อจากข้อ 2.2 เพื่อตรึงแถบค้นหาและตัวกรองภาคการศึกษาให้อยู่ด้านบนของหน้าจอตลอดเวลา ช่วยให้ค้นหาได้ทันทีโดยไม่ต้องเลื่อนจอกลับไปด้านบน		 100%
3. ตั้งค่าพิกัดสถานประกอบการ ☑ 3.1 ผู้ดูแลระบบสามารถระบุพิกัดจีพีเอส (ละติจูด/ลองจิจูด) ของสถานที่ตั้งสถานประกอบการของนิสิตแต่ละคนเข้าสู่ฐานข้อมูลได้ เพื่อเป็นฐานข้อมูลตรวจสอบพิกัดตอนเช็คอิน ได้เพิ่มฟังก์ชันให้นิสิตสามารถช่วยระบุและตั้งค่าพิกัดสถานประกอบการของตนเองได้เพิ่มเติมในส่วนของนิสิต เพื่อความแม่นยำสูงสุด 100%
4. สรุปรายงานและส่งออกไฟล์ ☑ 4.1 ผู้ดูแลระบบสามารถประมวลผลข้อมูลการลงพื้นที่และดาวน์โหลดไฟล์รายงาน Excel (.xlsx) สรุปประวัติการตรวจนิเทศงานแยกตามกลุ่มได้ - 100%
☑ 4.2 ผู้ดูแลระบบสามารถดาวน์โหลดใบสรุปผลประเมินคะแนนนิเทศของนิสิตทั้งหมดเป็นรูปแบบไฟล์ PDF (.pdf) ได้ - 100%
☑ 4.3 ระบบสลับสิทธิ์การใช้งานแบบรวดเร็ว (Quick Role Selector) เพื่อการทดสอบและตรวจสอบการแสดงผลในแต่ละบทบาท (Admin, Advisor, Student) ฟังก์ชันพัฒนาใหม่/ปรับปรุง
พัฒนาขึ้นเป็นเครื่องมือสนับสนุนสำหรับผู้ดูแลระบบและคณะกรรมการ ในการตรวจสอบความถูกต้องของการแสดงผลและสิทธิ์การเข้าถึงในแต่ละบทบาทได้อย่างสะดวก รวดเร็ว และปลอดภัย		 100%

3.2 ขอบเขตของอาจารย์นิเทศ (Faculty Advisor)

\n\n\n\n\n\n\n\n\n\n\n\n\n\n\n\n\n
ฟังก์ชันการทำงาน รายละเอียด หมายเหตุ ความสำเร็จ
1. ลงทะเบียนและเข้าสู่ระบบ ☑ 1.1 อาจารย์ลงทะเบียนเข้าใช้งานแอปพลิเคชันด้วยอีเมลมหาวิทยาลัย (@ku.th) และตั้งรหัสผ่าน โดยระบบจะตรวจสอบสิทธิ์ Pre-registered หากผ่านเกณฑ์จะคัดกรองบทบาทเป็น 'อาจารย์นิเทศ' โดยอัตโนมัติ - 100%
☑ 1.2 อาจารย์เข้าสู่ระบบผ่านแอปพลิเคชันเพื่อเริ่มต้นใช้งานด้วยบัญชีที่ลงทะเบียนไว้ มีการเพิ่มการยืนยันตัวตนด้วยรหัส OTP 8 หลัก ร่วมกับการเข้าสู่ระบบเพื่อความปลอดภัย 100%
☑ 1.3 อาจารย์สามารถออกจากระบบ (Logout) เพื่อความปลอดภัยของข้อมูลบัญชีผู้ใช้ได้ - 100%
2. จัดการห้องเรียนจำลอง ☑ 2.1 อาจารย์สามารถเข้าตรวจสอบรายชื่อ ข้อมูลเบื้องต้น และสถานที่ฝึกงานของนิสิตทุกคนในหมู่เรียนความดูแล (หมู่ 700 และ 800) ได้ในหน้าเดียว จากเดิมที่แสดงผลนิสิตทุกหมู่รวมกัน จึงได้มีการปรับปรุงแยกห้องเรียนเป็นสัดส่วนชัดเจนตามข้อ 2.3 100%
☑ 2.2 อาจารย์สามารถตรวจเช็คประวัติการส่งแบบฟอร์มเอกสาร Form 01 - 11 ของนิสิตรายคน รวมถึงกดยกเลิกการตรวจเพื่อส่งตีกลับแก้ไขได้ จากเดิมที่รายการงานแสดงผลตามลำดับทั่วไป จึงได้เพิ่มฟังก์ชันการจัดเรียงตามข้อ 2.4 100%

6. ประโยชน์ที่คาดว่าจะได้รับ

  1. เพิ่มประสิทธิภาพในการบริหารจัดการระดับภาควิชาและคณะฯ: มีระบบสารสนเทศส่วนกลางที่สามารถติดตามภาพรวมและสถานะการออกตรวจนิเทศงานสหกิจศึกษาได้อย่างถูกต้อง เป็นปัจจุบัน และโปร่งใส
  2. อำนวยความสะดวกแก่อาจารย์นิเทศในการปฏิบัติงาน: อาจารย์สามารถตรวจเช็ครายชื่อนิสิตแยกตามหมู่เรียน (700/800) บันทึกผลการนิเทศงาน ตรวจรับเอกสาร Form 01 - 11 และสแกนเช็คอินผ่านกล้องสมาร์ทโฟนได้อย่างรวดเร็ว
  3. ยกระดับความน่าเชื่อถือด้วยหลักฐานเชิงประจักษ์: มีระบบตรวจจับพิกัด GPS รัศมี 500 เมตร และคลังภาพถ่ายหลักฐานการลงพื้นที่จริง ป้องกันข้อผิดพลาดและการเช็คอินนอกสถานที่
  4. ลดความผิดพลาดในการจัดการข้อมูลนิสิต: ผู้ดูแลระบบสามารถตรวจสอบความถูกต้องของข้อมูลผ่านระบบพรีวิว Excel ขนาดใหญ่เต็มความกว้าง 100% ก่อนนำเข้า และส่งออกรายงานสรุปผลการนิเทศได้ทันที
  5. สร้างความพึงพอใจและความสะดวกแก่นิสิต: นิสิตสหกิจศึกษาสามารถติดตามวันเวลานัดหมายที่ตรงกัน ทราบผลการตรวจเอกสาร และดูผลการประเมินสะท้อนกลับจากอาจารย์ได้แบบเรียลไทม์

7. การรับรองขอบเขตของโครงงาน

จากขอบเขตของโครงงานข้อที่ 1 ถึงข้อที่ 6 ผู้จัดทำได้ปรับปรุงแก้ไขเพิ่มเติมร่วมกับอาจารย์ที่ปรึกษา และคณะกรรมการ เพื่อเป็นเกณฑ์ในการพิจารณาคะแนนตามความสมบูรณ์ของโครงงานในรายวิชา 01418499 โครงงานวิทยาการคอมพิวเตอร์ ภาควิชาวิทยาการคอมพิวเตอร์ คณะวิทยาศาสตร์ มหาวิทยาลัยเกษตรศาสตร์
